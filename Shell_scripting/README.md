# Shell Programming

This directory contains Bash exercises for variables, input, conditions, tests, system information, and process output.

## Scripts

| Script or directory | Description |
| --- | --- |
| `hello.sh` | Basic shell output |
| `variable.sh` | Variables and interpolation |
| `input.sh` | Reading user input |
| `condition.sh` | Conditional logic |
| `test.sh`, `test1.sh` | Shell test expressions |
| `system_info.sh` | Displays system information |
| `system-info-project/` | Structured system information project with documentation and sample output |
| `demo/` | Example process output |
| `hello/` | Runtime output from the hello exercise |

## Run a Script

From this directory, make a script executable and run it with Bash:

```sh
chmod +x hello.sh
./hello.sh
```

The system information project has its own instructions in [`system-info-project/README.md`](system-info-project/README.md).
